### 1.	Project Title 
A data-driven insurance dashboard analyzing policies, claims, premium amounts, and customer demographics using visual KPIs and charts.
### 2.	Short Description / Purpose
An insurance analytics dashboard that visualizes policies, claims, premiums, and customer trends to provide clear insights into business performance. It exists to support data-driven decision-making by simplifying complex insurance data into actionable KPIs and visuals.
### 3.	Tech Stack
List the key technologies used to build the dashboard.

The dashboard was built using the following tools and technologies:<br>
•	📊 Power BI Desktop – Main data visualization platform used for report creation.<br>
•	📂 Power Query – Data transformation and cleaning layer for reshaping and preparing the data.<br>
•	🧠 DAX (Data Analysis Expressions) – Used for calculated measures, dynamic visuals, and conditional logic.<br>
•	📝 Data Modeling – Relationships established among tables (resorts, snow, and data_dictionary) to enable cross-filtering and aggregation.<br>
•	📁 File Format – .pbix for development and .png for dashboard previews
### 4.	Data Source
The dashboard uses structured insurance data sourced from a simulated/CSV dataset containing policy, customer, premium, and claims records. The data is organized into relational tables (such as customers, policies, and claims), cleaned and transformed to enable accurate analysis and meaningful visualizations.
### 5. Goal of the dashboard
To provide a clear and interactive view of insurance performance by tracking policies, claims, premiums, and customer trends, enabling stakeholders to monitor key metrics and make informed, data-driven decisions.
### 6.Business Impact & Insights
The dashboard helps identify trends in claims and premiums, monitor policy performance, and uncover customer behavior patterns. These insights support better risk assessment, improved pricing strategies, and more effective business planning.
